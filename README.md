## 🚀 Usage & Setup

### Clone the Repository

```bash
# Clone the repository
git clone git@github.com:imyash0722/wallpapers.git
cd wallpapers
```

### Note on Previews

- All thumbnails are housed inside the hidden directory `.previews/`. Because it is dot-prefixed, desktop wallpaper indexers and daemons (`swww`, `hyprpaper`, `feh`, `waypaper`, `nitrogen`, etc.) ignore low-resolution thumbnails automatically.

- Clicking any image preview above navigates directly to the uncompressed, high-definition source file.
